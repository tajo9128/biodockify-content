# BioDockify Website Content

Full export of learn.biodockify.com WordPress site.

## Structure

```
├── content/
│   ├── posts/          # 43 blog posts (markdown)
│   ├── pages/          # 5 pages (markdown)
│   └── media/
│       └── images/     # Uploaded media files
├── posts.json          # Raw API export
├── pages.json          # Raw API export
├── categories.json     # Categories export
└── media.json          # Media metadata
```

## Usage

Edit markdown files in `content/`. Sync back to WordPress anytime.
